# Project-Electronic-Store_Analysis
Analyzing data from e-comerce


This project analyzes customer and sales data using Python, pandas, matplotlib, and seaborn.

## Features
- Data cleaning and preprocessing
- Handling missing values
- Removing duplicate records
- Merging multiple tables
- Revenue analysis by category, city, and month
- Customer performance analysis
- Data visualization with bar, line, and pie charts

## Technologies
- Python
- pandas
- matplotlib
- seaborn

## Skills Demonstrated
- Data cleaning
- Data merging
- GroupBy operations
- Datetime handling
- Data visualization
- Business insight generation
